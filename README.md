# About Me:

I have hands-on experience building practical, real-world applications including a Machine Learning-based Brain Tumor Detection system, ATM Simulation, and a Text Analyzer, demonstrating my ability to design, develop, and deliver functional solutions. I am currently working on strengthening my backend engineering skills by building scalable applications and improving my understanding of modern development practices, while actively learning advanced Python, APIs, databases, and system design. I am open to remote and on-site opportunities and looking to collaborate on impactful projects related to backend systems and AI. You can ask me about Python, backend development, machine learning fundamentals, and data handling. A fun fact about me is that I enjoy simplifying complex problems into clean, efficient, and maintainable code. I am highly motivated to contribute to growth-driven organizations and continuously evolve as a professional Software Engineer in competitive local and global environments.
